# The VIGIL icon

- `vigil.svg` is the source: a globe with one marked cell, in the theme's own colours (`Background`, `Accent`, `Positive`). The web viewer uses it as its favicon.
- `vigil.ico` is the same drawing at 16, 20, 24, 32, 40, 48, 64 and 256 pixels, for the desktop app's exe and windows. The smallest sizes use heavier lines and drop the meridian so they stay legible.

If the drawing changes, change both files together.
