The AI Detective

It answers only from the findings

You ask

A plain question

About a place, a variable or a finding you have open.

It looks things up

Tool calls

It searches the findings, fetches one, or reads what the scan covered. It computes nothing.

It is checked

Grounding

Every number in the answer must be in a finding it cites. An answer that fails is not shown.

You see its work

On the globe

Each lookup is listed under the answer and drawn where it searched.

When the results cannot settle a question, it says so.

The language model never computes or alters a statistic. Every result is reproducible without it. In the demo: ask one question it can answer and point at the findings it cites, then ask one the data cannot settle and show it declining.
