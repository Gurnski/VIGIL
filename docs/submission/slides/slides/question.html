The question

What is changing on Earth, where, and how sure can we be?

Most tools start from a famous event and go looking for it. VIGIL starts from the data, tests every place the same way, and reports what it finds, including where it finds nothing.

The brief calls this discovery first, explanation second. California drought or Himalayan warming may come out of the scan, but they are never fed into it. Success is a defensible, repeatable process, not how many famous events it recognises.
